# Warung Sitanggang - Soto Banjar Khas Kalimantan

Website promosi makanan modern untuk "Warung Sitanggang", menyajikan menu-menu autentik khas Kalimantan Selatan seperti Soto Banjar, Sate Ayam Banjar, dan Kue Bingka.

## Fitur Unggulan
- **Modern & Responsive UI**: Menggunakan Tailwind CSS untuk tampilan premium, dinamis, dan responsif di semua perangkat.
- **Pencarian Menu**: Cari soto, lauk, atau minuman dengan mudah langsung dari homepage.
- **Dashboard Admin**: CRUD (Create, Read, Update, Delete) lengkap dengan proteksi sesi login.
- **Validasi Form**: Keamanan dan feedback real-time saat login maupun mengelola menu (upload gambar, batasan harga, panjang teks).

## Teknologi
- **Framework**: CodeIgniter 4 (PHP 8+)
- **Styling**: Tailwind CSS v4 (CDN)
- **Database**: MySQL (Soto Banjar)
